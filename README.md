# Cleaning Robot

A cleaning robot project based on Arduino, implemented in C++.

## Overview

This repository contains code for an Arduino-based cleaning robot. The robot is designed to automate cleaning tasks and can be extended with various sensors and modules for improved functionality.

## Features

- Arduino-based control system
- Written in C++
- Modular design for adding sensors and cleaning modules

## Getting Started

1. Clone the repository:
   ```sh
   git clone https://github.com/Aladhar/cleaning_robot.git
   ```

2. Open the code in your preferred Arduino IDE.

3. Upload the code to your Arduino-compatible board.

## Requirements

- Arduino-compatible microcontroller
- C++ compiler (Arduino IDE)
- Cleaning module/sensors (as needed)
